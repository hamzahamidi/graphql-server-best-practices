# Privacy policy

Last updated: October 5, 2026

GraphQL Server Best Practices is a skills-only plugin. It provides written instructions for GraphQL server work. It has no MCP server, connected app, backend service, analytics, or telemetry.

## Information handled by the publisher

The publisher does not collect or receive prompts, conversation content, source code, files, account identifiers, or plugin usage data through this plugin. The plugin does not send information to the publisher or to third-party services.

The AI host that runs the skill, such as ChatGPT, Codex, Claude Code, or another supported agent, may process the prompts and repository context supplied to it. That processing is governed by the host provider's privacy policy and the user's account settings. The publisher does not receive that information through this plugin.

## Retention, sharing, and controls

The publisher retains no information collected through the plugin because the plugin does not collect or transmit it. The publisher does not share plugin user data with recipients.

Users control whether to invoke the skill and what context to provide to their AI host. They can stop using or remove the skill at any time. The host provider's privacy controls apply to information processed by that provider.

The public source repository is hosted by GitHub. Visits to GitHub are subject to GitHub's privacy policy. The plugin makes no GitHub requests at runtime.

For privacy questions, open an issue in the [repository](https://github.com/hamzahamidi/graphql-server-best-practices/issues). Do not include private code or personal information in a public issue.
